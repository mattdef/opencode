# Scalping Quick Reference Card

Print this or keep it open during trading sessions.

---

## ⚡ 7-STEP CHECKLIST (Do Every Trade)

```
□ 1. WEATHER    → Market type? Liquidity zones? 4H trend?
□ 2. NEWS       → Calendar checked? Avoid news ±5min?
□ 3. LEVELS     → Top-down OB analysis complete?
□ 4. SCENARIOS  → 2-3 probable paths mapped?
□ 5. CONFIRM    → CHoCH / Support hold / Candle close?
□ 6. EXECUTE    → All steps above done? Click.
□ 7. MANAGE     → SL at invalidation, TP at liquidity
```

---

## 🎯 LIQUIDITY ZONES (Your Edge)

| Zone | What It Is | How To Use |
|------|-----------|------------|
| **Equal Highs** | Multiple tops, same level | Stop losses above = price magnet |
| **Equal Lows** | Multiple bottoms, same level | Stop losses below = price magnet |
| **Trendline** | Diagonal stop clusters | Price sweeps then reverses |

**Rule**: Price ALWAYS grabs liquidity before the real move.

```
4H → 1H → 30M → 15M → 5M → 1M
 │     │     │     │     │     │
 │     │     │     │     │     └─ Precise entry
 │     │     │     │     └─ Working zone
 │     │     │     └─ Context
 │     │     └─ Refine
 │     └─ Major levels
 └─ Overall context
```

**Never skip timeframes.**

---

## ✅ ENTRY CONFIRMATIONS

### 1. CHoCH (Change of Character)
```
Price hits level → takes out previous high/low → reverses
```
Best for: Normal conditions

### 2. Support Zone Hold
```
Price approaches level → small support holds → bounces
```
Best for: Clean setups

### 3. Candle Close
```
Price hits level → bearish/bullish candle closes → enter
```
Best for: Fast/volatile markets

## 🛑 STOP LOSS RULES

| ❌ Wrong | ✅ Right |
|----------|----------|
| Too tight (stops before scenario plays) | At invalidation point |
| Too loose (defeats the level) | Above/below the OB |
| Arbitrary number | Based on structure |

**If SL hit → Scenario invalidated → Move on**

---

## 📰 NEWS RULES

- **Never trade** 5 min before/after high-impact news
- **Mark** news times on chart with vertical lines
- **Reduce size** or **sit out** during news windows
- **Sources**: Calendar + Twitter + Financial Juice

---

## 🧠 MINDSET

- Process > Outcome (follow steps even if last trade lost)
- No ego (flip bias in minutes if wrong)
- Market owes you nothing
- 90% of work is preparation
- If any step missing → NO TRADE

---

## 📈 PARTIAL PROFITS

Take profits in stages:
1. First target: Take 50% at first liquidity zone
2. Second target: Let rest run to next zone
3. Move SL to breakeven after first partial

This smooths your equity curve.
